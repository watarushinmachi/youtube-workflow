# LINEスタンプ 180日戦略（実行計画）

共有用ページ：https://claude.ai/code/artifact/af9e0f9d-2f3d-4068-b37b-b2737f69b3ed
前提資料：[market-research.md](./market-research.md)（市場調査・穴場5案）

## 前提がひっくり返った

| これまでの想定 | 一次情報で分かったこと |
|---|---|
| LINEスタンプはストック型の不労所得。良いものを1セット作れば放置で売れ続ける | **個別販売の賞味期限は約1ヶ月、長くて約6ヶ月。** 放置したセットは確実に死ぬ。ストックになるのは**販売から180日を超えた後**、別の仕組みで |

出典：約10年・330種類・受取額1,000万円弱のクリエイター urajo 氏「[ラインスタンプの賞味期限](https://note.com/urajo_stamp/n/n1197ba136bbe)」。販売直後に大きく売れ、その後は徐々に売れなくなるのが典型パターンと明言されている。

> **この戦略の一行**
> 個別販売（1〜6ヶ月で枯れるフロー）を数で回し続け、180日後に立ち上がるプレミアム（ストック）へバトンを渡す。1階と2階を同時に建てる。片方だけではどちらも成立しない。

## 1. 稼いでいる人の実数（一次情報）

| クリエイター | 稼働 / 制作数 | 実績 | 読み取れること |
|---|---|---|---|
| **バランス** | — | **月商19万円を2ヶ月連続**（1日30〜50個販売＋プレミアム1日5,000〜6,000送信） | 個別販売は日1,000〜2,000円＝月3〜6万円。**残りはプレミアム＝収益の主体は2階** |
| urajo | 約10年 / 約330種類 | 受取額 約1,000万円弱 | 売上をLooker Studioで可視化して運用。**分析前提の量産体制** |
| りんりんラボ | 10年 / 400種類超 | 受取額 1,000万円超 | **1,000万円到達には10年 × 300〜400種類** |
| はせがわじゅん | 8年 | 「病んではないけど、元気もない」約85,000円 / 「意味分からんし金もない」約40,000円 | **1セットの生涯売上は当たって数万円** |
| マツモトユキエ | 7年 | 月10万円を達成 | 月10万円ラインまで7年 |
| 市場全体 | — | 販売総額1,000億円超 / 売上1億円以上のクリエイター150人以上 | 母数350万種類に対して150人 |

**結論：支配変数は画力でもアイデアでもなく「継続年数 × 制作数」。** 1セットの生涯売上が数万円である以上、数を出さない限り金額は積み上がらない。逆に、制作を仕組み化できるチームには構造的な有利がある。

## 2. なぜ継続年数が複利になるのか

```
売上イメージ（1セットあたり）

個別販売  ▇▇▇▇▆▅▄▃▂▁                        ← 出した瞬間が天井。1〜6ヶ月で枯れる
プレミアム            ▁▂▃▄▅▆▆▇▇▇▇▇▇▇▇      ← 180日を超えてから立ち上がり、積み上がる
          └─0──30日─90日─180日──1年────2年→
                            ↑ プレミアム対象化
```

|  | 1階：個別販売 | 2階：プレミアム |
|---|---|---|
| 性質 | フロー。出した直後がピーク | **ストック。積み上がる** |
| 寿命 | 約1ヶ月、長くて約6ヶ月 | 対象化後、継続して発生 |
| 参加条件 | 販売開始した時点で発生 | **販売から180日以上経過したスタンプのみ** |
| 分配の決まり方 | 売れた本数 × 約42円 | **送信したユーザー数のシェア**（2026年7月改定：サブスク登録者数 × 単価12円税別 × 送信割合） |
| 勝ち方 | 検索で見つけてもらう | とにかく**使われる** |

**実績データとの整合**：8年継続クリエイターの年収推移は 1年目1,096円 → 2年目22,272円 → 3年目82,453円。1年目のセットが2年目にプレミアム原資へ変わり、そこに新作が重なる二階建てモデルでこの複利カーブは説明がつく。**リリース頻度が、そのまま1年後のストック残高を決めている。**

## 3. 作るものは2種類ある

1階と2階では勝つ条件が正反対。同じセットで両取りはできないので意図的に作り分ける。

| | 特化型セット（1階） | 汎用型セット（2階） |
|---|---|---|
| 狙い | 検索経由の**個別販売** | プレミアムの**送信ユーザー数シェア** |
| 語彙 | 状況を限定した一言（「お迎え着いた」「今から夜勤」「薬もらってきた」） | 誰にでも送れる一言（「了解」「ありがとう」「おつかれさま」） |
| 根拠 | 検索対象は**スタンプ名・説明文・クリエイター名**。複合語で拾われれば競合が薄い場所に立てる | 2023年に最も送信されたのは「中山きんに君 パワー!!スタンプ」。LINE公式が挙げた理由は**「ほとんどのユーザーが知っている＝誰にでも送れる」** |
| 寿命 | 短い。**数で回す前提** | 長い。180日後に効き始める |
| 配分 | リリースの **2/3** | リリースの **1/3** |

特化型で汎用語彙を並べても検索で埋もれ、汎用型で状況を限定しても送信されない。**混ぜないこと。**

## 4. 制作の型（原価を殺さない）

| ルール | 内容 | 理由 |
|---|---|---|
| **キャラは1体を使い回す** | キャラクターを毎回作らない。**同じキャラの語彙だけを差し替えて別セットにする** | 量産の肝。同時にシリーズ化になり1年を通した需要が立つ |
| 1セット8点 | 最小構成。実働**2人日を上限**にする | 賞味期限1〜6ヶ月に対して工数が見合わなくなる |
| AIはラフまで | 下書き・アイデア出しに限定。**人の作画・仕上げを必ず挟み、AI使用は正確に申告** | AI生成のみで制作されたものは審査対象から除外され得る |
| まず日本のみ販売 | 販売エリアに日本以外を含めない | 審査が1〜2日延びる。メッセージスタンプは世界同時発売が不可 |
| **プレミアムは必ず対象にする** | 全セットをプレミアム対象で登録 | **対象外＝2階を自分で捨てること** |
| 審査は2〜4日で読む | 公式目安は数時間〜約2日、実務では平均2〜4日・長くて5日 | 季節ものは投入日から逆算して申請 |

## 5. 初動の打ち手

1. **説明文に想定検索語を仕込む。** 検索対象はスタンプ名・説明文・クリエイター名の3つ。「看護師 夜勤 シフト」のように買う人が打ちそうな語をそのまま入れる
2. **特集期間に合わせて販売開始する。** 特集対象は「審査承認後、特集期間内に販売開始したもの」。**承認が下りてもすぐ売り出さず、特集期間まで待つ判断があり得る**
3. **自分で1つ買って 0→1 にする。** 0が1になるとランキングに反映され、ニッチな検索語なら1ページ目に出ることがある（月商19万円クリエイターの公開手法）
4. **導線はLINE STOREに寄せる。** 同じ120円でもLINE STORE経由約42円 / アプリ内約31円。**リンクの張り方だけで手取りが3割変わる**
5. **投入日を選ぶ。** 季節ものはイベント1〜2週間前。給料日前後（25日前後）と連休前も狙い目。審査2〜4日を逆算
6. **「使われているところ」を見せる。** 口コミの実体は友だちが使っているのを見て欲しくなること。**買う人ではなく受け取る人が次の買い手**。トーク画面で目を引く設計に
7. **売上データを初日から蓄積する。** 1,000万円クラスは全員が可視化して運用している

## 6. 12週間の実行計画

| 週 | やること | 成果物 |
|---|---|---|
| W1 | 穴場5案をLINE STOREで実測（語彙検索→ヒット数・上位作者・最終更新日）。事業形態決定、アカウント開設、口座・税務、規約読み合わせ | 参入ジャンル2つの確定 |
| W2 | キャラ1体を設計（以後すべてで使い回す）。語彙リスト作成 → **第1弾（特化型）8点**を制作・申請 | キャラ設定書・語彙リスト・第1弾申請 |
| **W3–4** | 審査通過 → 販売開始。初動7手を全部打つ。並行して**第2弾（汎用型）**を申請 | **2セット公開。制作原価（実働工数）の初回実測** |
| W5–12 | **隔週リリースを固定運用**（計4セット追加、特化3 : 汎用1）。同時に法人提案資料を作成し既存クライアント3社に打診 | 公開6セット / 法人打診3社 |
| W13 | 90日レビュー。セット別の販売数・工数・利益率を突き合わせ続行判断 | 継続 / 縮小の意思決定 |
| **7ヶ月目** | **第1弾がプレミアム対象化。**2階の数字が出始める。送信ユーザー数を見て特化 : 汎用比率を調整 | **本当の損益が見えるのはここ** |

> **注意**：90日時点ではこの事業の収益力はまだ測れない（プレミアムは180日後）。90日レビューで見るべきは売上額ではなく**「隔週リリースを工数上限内で回せたか」という運用能力**。ここが回らないなら先も回らない。

## 7. KPI

| 指標 | 基準の出どころ | 90日 | 1年 |
|---|---|---|---|
| 公開セット数 | 1,000万円級は10年で300〜400種類＝年30〜40 | 6 | 24 |
| 1セットの制作工数 | 賞味期限1〜6ヶ月に見合う上限 | 実働2人日以内 | 1.5人日以内 |
| **プレミアム送信数** | **「1日1,000送信あればいい方」**（月商19万円クリエイターの基準） | —（対象化前） | 1日1,000送信 |
| 1セット生涯売上 | 当たって数万円（8年継続クリエイターの実額 4万・8.5万円） | — | 上位1セットで2万円 |
| 法人受託 | 制作単体では1.5〜10万円のコモディティ。施策設計込みで取る | 打診3社 | 受注1件 |

**撤退基準（更新）**：企画書の基準に1本追加する。**6セット出してプレミアム対象化後の送信数が1日100に届かないなら、語彙設計が間違っている。** その場合はジャンルを変えるのではなく、まず説明文と語彙リストを作り直して同じジャンルで再挑戦。それでも動かなければ自社スタンプ（ラインB・C）を止め、法人受託に一本化する。

## 8. やらないこと

- **1セットに凝る** — 生涯売上が数万円の商品に何日もかけた時点で赤字が確定する
- **汎用のかわいいキャラで真っ向勝負** — 350万種類の本体。プロが密集していて画力で勝てない
- **韓国風・くすみカラーなどトレンド追随** — 流行のど真ん中は後発が最も不利
- **プレミアム対象外にする** — 収益の主体である2階を自分で放棄することになる
- **最初から全世界販売** — 審査が延び、メッセージスタンプは世界同時発売不可。回転が落ちる
- **90日の売上額で成否を判断** — プレミアム前なのでそもそも測定できていない
- **「スタンプを作ります」で法人営業** — 制作代行の相場は40個で1.5〜4万円。この売り方では抜けられない
