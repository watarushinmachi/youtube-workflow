# LINEスタンプ市場調査（2026-08）

共有用ページ：https://claude.ai/code/artifact/bf1f667d-203e-4dfd-94bf-959e44d1f536

## 調査サマリ

1. **市場は完全に飽和。** クリエイターズスタンプは累計350万種類超、登録クリエイターの**9割以上が売上ゼロ**。素人が1年出し続けて売れたのは約96個＝年3,000円前後が標準的な実績。
2. **「絵の上手さ」で競うフェーズは終わっている。** 勝負どころは画力ではなく「誰の・どの場面の・どの一言を埋めるか」という語彙設計。企画・台本チームが戦える土俵。
3. **需要のボリュームゾーンは40代〜50代以上。** 公式データで40代の購買決定要因は「毎日使えるか」。実用フレーズが売れている。供給は若者向けの可愛いキャラに偏っており、構造的なズレがある。
4. **穴場は「ニッチ」ではなく「レッドオーシャンの空き軸」。** ニッチすぎると母数が足りず伸びない。母数の大きい赤い海を選び、その中で誰も埋めていない**状況の軸**を刺す。
5. **法人受託の相場は想定より一桁安い。** 制作代行は40個で1.5〜4万円、制作会社でも5〜10万円。企画書の「1件20万円」は制作単体では成立しない（訂正済み）。

価格帯は120 / 250 / 370 / 490 / 610円の5段階。ほとんどが最低価格に設定されている。

> **設計上の含意**：アニメーションは「手取り約1.4倍」かつ「競合が薄い」。作るのが面倒なので個人は避けるが、**動画制作チームにとってはその面倒くささがそのまま参入障壁になる。**

## 年代別の需要地図（LINE公式のクリエイター向けデータ）

| 年代 | 買う理由・コンセプト | デザインの好み | 供給 |
|---|---|---|---|
| 10代 | シュールでクスッと笑える。だじゃれ、食べ物が喋る。学生の日常会話×人物イラスト。文字だけも人気（定番1位「けたたましく動くクマ」29.2%） | 優しいタッチ。絵文字は韓国風・推し活風 | 過密 |
| 20代 | 絵文字中心。ファッション由来のトレンドが流入 | くすみカラー、ゆるいキャラ | 過密 |
| 30代 | キャラの可愛さより**動き・仕草のコミカルさ**と個性 | 動きで魅せる＝アニメ適性が高い | やや薄い |
| **40代** | **毎日使えるかが決め手。**家族間の実用連絡（「ごはんどうする？」「お迎え着いた」「いってらっしゃい」「ファイト」）。母から家族へのシュール系「勉強しろ」「反抗期？」 | **色背景つきで読みやすいもの** | **薄い** |
| **50代以上** | 季節の挨拶、上品。中高年・シニアマダム・おじいちゃんの人物イラスト×日常会話。安否確認などの実務用途 | **デカ文字。見やすさ最優先** | **薄い。画力の要求が最も低い** |

40代がよく使うタグ上位＝了解 / おはよう / OK / ありがとう / おつかれさま。この5語では差がつかない。差がつくのは「その人の生活に固有の一言」。

## レッドオーシャンの判定シグナル

1. **プレミアムに大量登録されている** — 古参が陣取り済み
2. **プロのイラストレーターが成立させている** — 画力で殴り合う土俵（例：浮世絵）
3. **「誰でも使える」汎用スタンプ** — 供給が無限
4. **いま流行っているデザイン** — 韓国風・くすみカラー・ゆる手描きはプロが密集済み

> **同時に成り立つ罠**：ニッチすぎるジャンルも売れない。そのジャンルで1位を取っても母数が小さいと伸びない。**探すべきは“ニッチ”ではなく、母数の大きい赤い海に残った“空き軸”。**

## 穴場5案

### 1. 家族の「実務連絡」スタンプ 〔最優先〕
- **赤い海** あいさつ・家族・ねぎらい（最大の激戦区）
- **空き軸** 可愛さではなく**生活の実務**。段取りを詰めるための一言
- **語彙例** ごはんどうする？ / お迎え着いた / ◯時に出る / 駐車場で待ってる / 先に食べてて / 洗濯回した / 薬飲んだ？ / 鍵閉めた？ / 今日は遅くなる
- **根拠** 公式データで40代の購買決定要因が「毎日使えるか」と明示。実売例として該当フレーズが挙がっている。供給は若者向けに偏り、需給がずれている
- **優位性** **画力をほぼ要求しない。**必要なのは絵の巧さではなく語彙の解像度
- **リスク** 地味で拡散しない。初速が導線設計に完全依存

### 2. シフト勤務者の生活時間帯 〔推奨〕
- **赤い海** 「おつかれさま」系の汎用ねぎらい。看護師・介護士向けセットも多数存在
- **空き軸** 既存は**職業ネタで笑う**もの。**その人が実務で毎日打つ言葉**は手薄
- **語彙例** 今から夜勤 / 明け / これから寝る / シフト代われる？ / 遅番です / 今日休み取れた / 連勤終わった / 仮眠入ります
- **根拠** 看護師・介護士・理学療法士・病院スタッフ向けは既に多数＝需要実証済みの赤い海。医療・介護・物流・小売へ横展開が効く
- **リスク** 職種ごとに作り分けると原価が膨らむ。まず1職種で検証

### 3. シニア×デカ文字の「実務」枠
- **赤い海** デカ文字・シニア向けスタンプ自体は大量にある
- **空き軸** 挨拶ではなく**安否確認・通院・服薬など「介護する側／される側」の連絡**
- **語彙例** 元気にしてる？ / 病院どうだった？ / 薬もらってきた / 今から行くね / 無事に着いた / なにかあったら電話して
- **根拠** 「デカ文字☆安否確認☆高齢者呼びかけ用」等が実在＝需要検証済み。50代以上は画力の要求水準が全年代で最も低い。高齢化で母数は増加方向
- **優位性** 買うのは離れて暮らす40〜50代の子ども側。**穴場1と購買者が重なり、同じ導線で売れる**
- **リスク** シニアは購入操作に不慣れ。プレゼント購入前提の設計・説明文が要る

### 4. アニメーション × 地味な実用語彙
- **赤い海** 静止画350万種類の物量勝負
- **空き軸** **動く側。**手取り約60円、かつ制作が面倒で個人が参入しにくい
- **根拠** 30代は「動き・仕草のコミカルさ」で選ぶという公式データがあり、需要と商品特性が噛み合う
- **優位性** 制作の面倒くささがそのまま参入障壁。動画編集の設備と人がいるチームにだけ、この障壁がない
- **リスク** 工数が跳ねる。静止画で当たった語彙を確認してから動く版に載せ替える順序を守る

### 5. 【B2B】プロモーションスタンプの企画・運用 〔収益の本命〕
- **赤い海** スタンプ制作代行（40個で1.5〜4万円のコモディティ）
- **空き軸** 制作ではなく**「獲得した友だちを離脱させないコンテンツ設計」**
- **根拠** LINEプロモーションスタンプは**一度の実施で約200万人の友だち獲得**が見込める広告商品。一方で「無料スタンプ目当てでDL後すぐブロック」が構造的課題とされ、**追加後のコミュニケーション設計が必須**と明記されている
- **優位性** その設計＝配信コンテンツの企画・制作は**YouTube制作チームの本業そのもの**
- **追い風** 2026年1月以降の掲載案件はアニメーション・BIG・エフェクト・カスタム・メッセージが**追加費用なしの標準機能**に
- **リスク** 予算承認プロセスが重くリードタイムが長い。自社実績が先に要る

## この調査の限界と検証手順

**調査環境からLINE STORE・ランキングサイトへの直接アクセスが遮断されていたため、各ジャンルの実際の競合セット数は数えられていない。** 上の5案は需要側の公式データとクリエイターの公開実績から導いた仮説であり、供給側の実測を伴っていない。投入前に必ず自分で確認すること。

1. **LINE STOREで語彙そのものを検索。** ヒット数ゼロ近辺＝ニッチすぎ、数百件＝レッドオーシャン。**10〜50件程度が狙い目**
2. **上位セットの最終更新日とクリエイター名を見る。** 同一作者が上位を占める＝陣取り済み。更新が数年前で止まっていれば余地あり
3. **プレミアム対象かを確認。** 大量登録されていたら古参の陣地
4. **上位セットのレビューと点数構成を読む。** 「この言葉が入っていれば買った」系の不満がそのまま語彙リストになる
5. **1案だけ8点セットで出して初動を測る。** 考えるより出して数えるほうが速い

1ジャンルあたり10〜15分。5案すべてで1時間強。

## 運用で効く細かい事実

| 項目 | 内容 |
|---|---|
| 初動がすべて | リリース直後の「新着（人気順）」での露出が売上を決める |
| 検索の対象 | スタンプ名・説明文・クリエイター名の3つ。**説明文への検索語仕込みは無料でできる最大の施策** |
| シリーズ化 | 同じキャラで春夏秋冬を展開すると1年を通して需要が立つ |
| 季節ものの投入 | イベントの**1〜2週間前**に販売開始。審査期間を逆算 |
| 売れやすいタイミング | 給料日前後（毎月25日前後）、連休前（金曜・祝前日） |
| メッセージスタンプの制約 | 世界同時発売ができない |
