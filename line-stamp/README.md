## 3行サマリ

- スタンプを作って売るだけでは稼げない。1セット120円が売れてクリエイター取り分は **約42円**（LINE STORE経由）。月10万円には月2,381セット必要。
- 勝ち筋は **法人受託（ラインA）**。既存のYouTube案件クライアントにアップセルできることが、我々の唯一の非対称優位。ただし売り物は「制作」ではなく **プロモーション施策の企画・運用**（制作代行の相場は40個で1.5〜4万円のコモディティ）。
- 90日で「審査を1周」→「法人1件受注」。達成できなければ量産ライン（C）は畳む。

## 収益ライン

| | ライン | 位置づけ | 90日目の合格ライン |
|---|---|---|---|
| A | 法人・クライアント受託 | 本命・収益の8割 | 受注1件以上・粗利10万円以上 |
| B | 自社チャンネル送客 | 中期・IP育成 | 1セット目 100個以上 |
| C | ロングテール量産 | 実験枠・上限あり | 月間分配額 5,000円以上 |

**撤退基準**：90日時点で「Aの受注ゼロ」かつ「Cが月5,000円未満」なら、ラインCは即停止。

## 押さえておく数字（2026年8月時点）

| 項目 | 内容 |
|---|---|
| 分配金 | （売上総額 − 手数料30%）× 50% ＝ 実質 **売上の約35%** |
| 120円スタンプ1セット | LINE STORE経由 約42円 ／ アプリ内スタンプショップ経由 約31円 |
| 送金 | 分配額 **1,000円以上** で申請可。毎月1〜10日頃は集計期間で申請不可 |
| 税務 | 個人事業形態で年間送金申請額が5万円超 → マイナンバー提出 |
| プレミアム | 2026年7月改定：サブスク登録者数 × 12円（税別）× 送信割合 |

## 最重要の規約リスク

**AIによって自動生成されたコンテンツのみで制作されたものは、審査対象から除外され得る。**
また申請時に「AIの使用」有無を正確に申告する義務がある。

→ AIはラフ・アイデア出しまで。**人による作画・仕上げ工程を必ず挟み、制作過程を記録に残す。**

> **2026-08 更新**：市場調査で前提が2つ変わった。
> ① 個別販売の**賞味期限は1〜6ヶ月**。作って放置では稼げず、収益の主体は販売180日後に立ち上がる**プレミアム**にある（→ `strategy.md`）。
> ② 制作代行の相場は40個で1.5〜4万円。法人受託は「制作」ではなく**プロモーション施策の企画・運用**で取る。

## 次のアクション（Day 1–14）

- [ ] LINE Creators Market アカウント開設（事業形態＝法人／個人を先に決定）
- [ ] 利用規約・審査ガイドラインをチームで読み合わせ（一次情報で料率を再確認）
- [ ] 銀行口座・税務まわりの準備
- [ ] 自社キャラで8点セットを1本、申請〜審査通過まで通す（目的：売上ではなく **プロセスと原価の実測**）
- [ ] 1セットあたりの実働工数を記録し、法人向け価格表のベースにする

## 着手前に決めること

- 事業形態（法人／個人）
- 作画リソース（社内／外部イラストレーター契約／都度発注）
- 既存クライアントへのアップセル可否（営業チーム確認）
- 初期予算（AI画像生成の商用ライセンス費・外注費・90日分の人件費枠）
- 画像規格（スタンプ／メイン／タブ画像のサイズ、点数、価格帯）を公式ガイドラインで最終確認
