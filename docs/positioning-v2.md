## 0. v1が外した理由を、先に確定させておく

「棚を読む」は、視聴者が使っていない言葉だった（630件中2件）。ここから条件が1つ出てくる。

> **第一想起を取りにいく言葉は、視聴者の頭にすでに入っている言葉でなければならない。**

脳内SEOは「頭の中で1位を取る」ゲームなので、まだ頭に無い言葉では、順位を争う棚そのものが無い。概念を先に教えてから1位を取るのは、後発には遠回りだった。

この条件で視聴者1,016件を数え直すと、**すでに頭に入っていて、しかも誰も陣地にしていない言葉が1つある**。

## 1. いちばん深い不信は「稼げない」ではなかった

不信のコメントを評価順に並べると、上位が全部同じことを言っている。

> **「せどりが専業の転売ヤーは底辺だけど、仕事しながらってのが賢いな。」（88👍）**
> 「転売ヤーは資本主義なので別に悪ではないし、皆さんすごい努力の賜物です（ズルして仕入れする奴は悪）。**しかし子を持つ親としては完全に敵ですね！**」（51👍）
> 「人それぞれの考えあってのことなんだろうけど **所詮やってることは転売ヤーと同じくくり**」（48👍）
> 「個人的には**安全靴の買い占めは勘弁してほしい**。現場の人たちは急に必要になるときがあるから。『その人たちがネットとかこの人から買えばいいでしょ』という考え方はやめてほしいな。」（23👍）
> 「やってることは転売仲介業者ですね。」（22👍）

**このデータセットで最も評価された批判は、全部これ。** 「稼げない」でも「詐欺だ」でもなく、**「それは人として胸を張れる仕事なのか」**を突いている。88👍のコメントは、せどり専業をはっきり「底辺」と呼んでいる。

しかも視聴者の側が、この問いを放置できずに自分で答えを書き始めている。

> 「転売は大量購入して供給を阻害して値段を釣り上げて売る行為を指して言われることが多いけど、せどりは掘り出し物を見つけて手数料を取って売る行為。**要するに供給を阻害するか供給を促進するかの違い。**」（14👍）
> 「商売の基本は転売だからな。」（17👍）
> 「転売と何が違うん？って思ったけど安く売ってるものを市場価格で売ってるって認識でええんかな？」（18👍）

**視聴者が発信者の代わりに弁明している。** ここに答えが用意されていないから、視聴者が埋めにいっている。

## 2. 発信者の側にも、同じ疑いがある

### うみぞうの最高評価の返信は、仕入れ技術ではない

業界最大手（688,960回の動画を持つ）のコメント返信を評価順に並べると、上位が全部**正当性の弁明**だった。

| 評価 | 何に答えているか |
|---|---|
| 57👍 | 「年商2200なら消費税だけで100万、薄利に感じる」への税金の説明 |
| **56👍** | **「所詮やってることは転売ヤーと同じくくり」への反論** |
| 35👍 | 「時間の切り売りでしかない」への反論 |
| 19👍 | 「転売と何が違うん？」への説明 |
| 10👍 | 「安全靴の買い占めは勘弁してほしい」への釈明 |

56👍の返信で、うみぞうはこう書いている。

> 「せどり → 商品と購入者を**近づける**もの／転売 → 商品と購入者を**遠ざける**もの」

**これは良い言い切りで、しかも高く評価されている。なのにコメント欄に埋まったままで、動画にはなっていない。** 需要が証明済みで、供給がゼロの状態。

### たっきー自身が同じ問題意識を口にしている

2025年9月の体制変更の動画で、部長を退いたたっきーはこう言っている（`docs/torehanbu-channel-research.md`）。

> 「せどり系YouTubeは**うさん臭いと思われている**／サポートの薄いスクールに課金してしまう人がいる。**うちが大きくなればそれを減らせる**」

そして、それを解くために**月50万円をHP制作・プレスリリース・メディア露出に使っている**。

**つまり、たっきーは既にこの陣地を取りにいっている。ただしチャンネルの外側（HPとPR）でやっていて、チャンネル本体は普通の仕入れ同行のままになっている。** たくと氏の成立条件（心から信じている正論であること）は、ここではもう満たされている。本人が自腹を切って証明しにいっているからだ。

## 3. 脳内SEOに当てはめる

たくと氏の型は「競合が入口を取っているなら、自分は出口を取る」。入口は視聴者が今口にしている欲求で、出口はその欲求が失敗した後に必ず辿り着く欲求を指す。

| | この市場では |
|---|---|
| **入口**（競合が全部取っている） | 利益商品を見つけたい／月◯◯万稼ぎたい |
| **失敗の後に必ず来るもの** | ①在庫が残る ②1回売れて続かない ③稼いだら税金と会社バレ ④**周りから転売ヤーと言われる** |

①〜③は作業で解ける。**④だけは作業では解けない。** そして④に当たった人は辞める。

> 「6000円のアイスコーヒーメーカーがHARDOFFで1000円だったので、メルカリで売ったら6000円で売れた。『せどりライフイケるかも？』と色めき立ったけど、**地方で掘り出し物見つけるのはなかなか難しくて後が続かなかった**」（18👍）
> 「**奥さんとか家族の理解を得られないって結構ありますよね**」（11👍）
> 「30年前にせどりを10年やって…**近所からも悪い事してると疑われる始末**」（1👍）

**この市場の出口は「稼げる状態」ではなく「続けられる状態」で、続けられるかどうかを決めているのは、金額ではなく周囲に説明できるかどうか。**

## 4. 案

### 案A：買い占めない側に立つ（推奨）

| | |
|---|---|
| **叩く流派** | 新品の店舗せどり＝ドンキ・イオン・家電量販店で新品をまとめ買いしてAmazonで売る型。うみぞう688,960回、こうじ402,829回。**市場で最も再生を取っているのがこの型** |
| **主張** | 中古の1点物しか扱わない。だから買い占めようがない。誰かが買えなくなる商品を、うちは1つも作らない |
| **キーワード候補** | 「買い占めないせどり」／「1点物のせどり」／「家族に言えるせどり」 |
| **視聴者の言葉か** | **入っている。** 「転売ヤー」は1,016件中12件、無促しで出てくる。最高評価の批判群がここ |
| **自己否定にならないか** | **ならない。** トレハン部はセカスト・オフハウスの中古アパレル／バッグ／腕時計が主戦場で、構造上まとめ買いができない |
| **リスク** | 名指しで叩けば燃える。新品系の発信者とは共演できなくなる |

**この案だけが持っている強み**：主張が精神論ではなく、**商材の性質から自動的に出てくる**。中古の1点物は買い占めが物理的に不可能なので、「やらない」と誓う必要すらない。他の誰かが真似しようとすると、扱う商材を中古1点物に変えるしかない。**参入障壁が商材そのものに埋まっている。**

**数字での裏付け（ただし弱い）**：転売ヤー系の批判は、新品・Amazon系の動画で782件中11件（1.4%）、中古・フリマ系で234件中1件（0.4%）。3.5倍の差があるが、**中古側は母数234件で1件なので、これだけで断定はできない**。仮説として扱い、中古系の動画をもっと集めて確かめる必要がある。

### 案B：手取りで言う

| | |
|---|---|
| **叩く流派** | 「月収◯◯万円」サムネ。業界の共通言語で、例外が無い |
| **主張** | 月収ではなく手取りで言う。消費税・所得税・Amazon手数料・保管料・交通費を全部引いた後の金額しか出さない |
| **キーワード候補** | 「手取りで言うせどり」／「せどりの手取り」 |
| **視聴者の言葉か** | 入っている。検算コメントが26件で、質問カテゴリの最高評価帯を占める |
| **根拠** | 「月収76万円になるには、利益率20％で380万円の売上が必要ですね」（58👍）／「年商2200なら消費税だけでもざっくり100万くらい…それにしては薄利に感じる」（41👍）／「月利とは粗利のことでしょうか？」（3👍）／「粗利益が80万か純利益が80万かはっきりしろよ」 |
| **リスク** | **自社の実績訴求が弱くなる。** 手取りで言えば数字は必ず小さく見える。スクール販売と正面から衝突する |

うみぞうは41👍の検算コメントに対して、**「年商2,200万ではなく年収2,200万です（年商は1.5億円ほど）」と訂正させられている**。トップランナーですら、数字の出し方で突っ込まれている。ただし**トレハン部がここを取ると、自社の「月利◯◯万達成」訴求と衝突する**ので、実行の難易度は案Aより高い。

---

### 案C：辞めた人に聞く

| | |
|---|---|
| **叩く流派** | 成功者1日密着。市場で最も再生を取るフォーマットだが、**全員が成功者しか出さない** |
| **主張** | 続かなかった人に話を聞く。なぜ止まったのかを本人に語らせる |
| **キーワード候補** | 「辞めた人に聞くせどり」／「続かなかった理由」 |
| **視聴者の言葉か** | 入っている。挫折の語りが具体的に集まっている |
| **根拠** | 「たまたま成功しただけみたいで**だいぶ沼りました**」（1👍）／「後が続かなかった」（18👍）／「**2、3年前にせどりおすすめ動画出している人が現在は出されていないので、辞めたのかなと思われる人もいます**」（4👍）／「自分にはここまで出来ないかもしれないといつも諦めて、結局何も出来ずに一歩が踏み出せず」（13👍） |
| **リスク** | **自社スクールの受講生が辞めた話に触れざるを得なくなる可能性がある。** 他社受講生や独学者に限定すれば回避できるが、その時点で主張が弱る |

**密着という最強フォーマットを使いながら中身を反転させる**ので、再生が落ちにくいのが利点。ただしリスクの読みが案Aより難しい。

### 案D：スクールの値段を先に出す

叩く相手は、全発信者が共通で使っている「LINE登録 → 個別 → 金額提示」という順番になる。視聴者側の根拠はある。

> 「**物販スクール代、お高いんでしょう？**」（1👍）
> 「スクール、って月額でかかるんですか？ それとも一時払いですか？ **視聴者も気になっている人が多いように感じるので質問しました**」（5👍）
> 「コンサル料が30万以上かかる物でした。**ネズミ講と何ら変わらない**」（1👍）

たっきーの問題意識（サポートの薄いスクールに課金してしまう人を減らしたい）と完全に一致する。**ただしこれはチャンネルのポジショニングというより、販売設計の変更**。案A〜Cのどれを選んでも、併せて実行できる。単独の第一想起にはなりにくいので、**案Aの補強として置くのが妥当**と見ている。

## 5. 推奨は案A。理由を4つ

1. **視聴者の頭にすでに入っている言葉で戦える。** v1の「棚」は2件だったが、「転売ヤー」は促されずに12件出てくる。脳内SEOの前提を満たしている唯一の言葉
2. **需要がすでに証明されている。** 業界最大手の最高評価の返信が、この弁明。しかも動画になっていない。需要あり・供給ゼロ
3. **自己否定にならない。** 中古1点物という商材の性質から自動的に出てくる主張なので、過去1,040本と1本も矛盾しない
4. **成立条件を満たしている。** たくと氏の「心から信じている正論であること」について、たっきーは既に月50万を払って証明しにいっている

### 掛け算（この組み合わせは競合に無い）

中古1点物 × 店舗（セカスト・オフハウス） × 買い占めない × 女性演者（TOMY・44歳） × 8年1,040本 × 複数演者

女性演者が効くのは、51👍の批判が**「子を持つ親としては完全に敵ですね」**だったからだ。**この批判をいちばん強く受ける層と、いちばん強く解ける立場が同じ**（子育てを終えた44歳の女性が、買い占めない仕入れを見せる）。

## 6. 実行の形 — 報告企画にしないこと

`docs/comment-insights.md` 8章で分かった制約をそのまま効かせる。トレハン部61本の中央値は4,070回で、出口を扱った過去4本の結果は割れていた。

- 報告型（「◯月に売れた商品を全公開」「赤字商品10選」）= 3,171／3,223回で沈む
- 実演に接続した型（「バッグ1年分・仕入れから実売まで」）= 9,996回・上位11%
- ノウハウ型（「売れ残りを即売れに変える15のコツ」）= 24,188回・上位7%

**つまり案Aも、「買い占めについて語る」動画にしてはいけない。** 仕入れ同行の画を保ったまま、その中で見せる。

**最初に打つ1本の案**：いつものセカスト／オフハウスの仕入れ同行を撮る。その中で、**買わなかった商品**を理由付きで出す。「これは利益が出るけど、まとめ買いになるから置く」を実際の現場で1回やる。タイトルは利益額で立てて、中身で見せる。

**測るもの**：再生数はチャンネル中央値4,070回と、実演系の通常レンジ4,000〜11,000回に対して比べる。コメントに「転売ヤー」「買い占め」の語が出るかどうかも数える（通常は1,016件中12件の水準）。
