## 2. 発信者は誰か（＝チャンネルの人格）

### 初代部長「たっきー」（滝沢・1988年生まれ／静岡出身／2児の父）

- 3ヶ月で6万円 → 4ヶ月目に月利74万円 → 6ヶ月目に脱サラ・起業
- 起業8ヶ月目で月利328万円 → 翌年1月に株式会社設立
- 講師業を卒業し物販スクール事業の運営側へ。受講生2,200名以上、教え子の最高月利325〜335万円
- モットー「仲間の為に道を切り開く」／「お小遣い3万円のパパ社長」という親近感キャラ

**＝「どん底からの逆転」を軸にした、物販スクール集客のための個人ブランド。**

### 2025年9月に体制が変わった（重要）
動画「【終了!?】トレハン部部長から大切なお知らせがあります。」(2025-09-07) で、たっきーが部長を引退。

- たっきー → 「ボス／ATM」を自称。広告運用・HP制作・プレスリリース/メディア露出・資金投下に専念（運営費は月50万円規模と発言）

- 明言された戦略: ①演者を増やす（男女とも）②「ママトレハン部」として別チャンネルを立ち上げる ③HP＋メディア掲載で「怪しくない・ちゃんとやっている」信頼性を獲得する
- 背景の課題意識: 「せどり系YouTubeはうさん臭いと思われている／サポートの薄いスクールに課金してしまう人がいる。うちが大きくなればそれを減らせる」

## 3. 発信テーマ

**軸：店舗せどり（セカンドストリート／オフハウス／ブックオフ／ハードオフ／トレファク）× メルカリ販売**
得意ジャンルは中古アパレル・バッグ・腕時計。Amazon/新品系ではなく「中古・実店舗・フリマアプリ」が完全に主戦場。

### コンテンツの型（6パターン）
1. **仕入れ同行・密着**（20〜60分／総集編は2〜4時間）— 最も再生が伸びる主力
2. **ノウハウ解説** — 梱包、写真撮影、出品文、リペア（電池交換・革の補色）、送料圧縮
3. **実売報告** — 「◯月に売れた利益商品TOP10」定例企画
4. **注意喚起** — メルカリ規約改定、悪質ユーザー、BAN対象のNG行為、古物商許可
5. **実績者インタビュー** — 受講生の月利達成ストーリー（スクール訴求と直結）
6. **マインド／挫折系** — 「真面目な人ほど稼げない」「主婦が挫折する理由」

### フォーマットの定型
- 長尺18〜30分が中心、週2〜3本、**毎回10:00投稿**で固定
- タイトル型: `【超有料級】` `【店舗せどり】` `【初心者必見】` `【要注意】` ＋ 数字 ＋「徹底解説／完全公開」
- 公開している仕入れ基準: **利益率30%以上・利益額2,000円以上**（コメント返信で明言）

## 7. 強み / 弱み

**強み**
- 8年・1,040本の蓄積と、店舗せどり×メルカリという明確なポジション
- 実演の生々しさ（ノーカット仕入れ、失敗も出す）
- TOMYによる長文・丁寧なコメント返信 → 視聴者との関係性が実際に濃い
- 12.5万文字の特典という、LINE登録のオファーの強さ
- 複数演者体制への移行で、属人リスクを下げにいっている

**弱み・伸びしろ**
- **ブランドの過渡期**：たっきー個人ブランド → チーム/法人ブランドへの移行中で、「誰のチャンネルか」が視聴者に伝わりきっていない
- **概要欄がたっきー時代のまま**（プロフィール・SNS・自己紹介動画リンクが全て旧体制）。現在の主演者TOMYの情報がゼロ
- **Shortsの停止**で、最大の流入源だった導線が止まっている
- 解説・マインド系の再生が実演系の1/3〜1/5。企画の当たり外れが大きい
- 登録者の伸びが鈍化（90日で+500人）。再生は回っているが登録に転換できていない
- 実績の証明（実売スクショ等）を求める声が出ており、信頼性の可視化が次の課題
