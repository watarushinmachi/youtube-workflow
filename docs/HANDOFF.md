## 次にやること：4の実行

### なぜ止まっているか
- vidIQ のクレジットが 0（次回リセット 2026-10-10 / プラン上限150）。`video_comments` は1ページ5クレジットなので、30本×全ページは構造的に賄えない
- リモート実行環境では `www.youtube.com` が egress proxy に遮断されていた（`www.googleapis.com` は疎通OK）
- → **YouTube Data API v3 のキーがあれば解決する**。コメント取得は1リクエスト=1クォータ、無料枠10,000/日。30本フル取得でも500未満

### 手順

1. Google Cloud で「YouTube Data API v3」を有効化 → APIキーを発行
   （キーの制限は「YouTube Data API v3 のみ」に絞っておく）

2. 環境変数に設定
   ```bash
   export YOUTUBE_API_KEY=xxxxx
   ```

3. 対象動画の選定（再生数ランキング）
   ```bash
   python3 tools/fetch_comments.py --stage videos
   ```
   → `data/candidates.json` と `data/selected_videos.json` が出る
   → 標準では **中古20本・新品10本**、1チャンネル3本上限。比率を変えるなら
     `--n-used 20 --n-new 10 --per-channel 3`

4. コメント取得（返信スレッド込み・全ページ）
   ```bash
   python3 tools/fetch_comments.py --stage comments
   ```
   → `data/comments.jsonl` に1動画1行で保存。途中で止まっても再実行で続きから

※ `data/` は `.gitignore` 済み。取得物はリポジトリに入らない。

## 議論の前提（ここまでの結論）

### 脳内SEOとは
たくと氏（@たくと.YouTube攻略）の概念。「視聴者の頭の中で、あるキーワードの第一想起を取る」ゲーム。
- 競合が入口（再生数）を取っているなら、自分は**出口**（売上）を取る
- **後発が有利**：先発は設計が緩いので弱点を突かれると弱い。大きい流派が立っているからこそ反対意見の流派が成立する
- 成立条件：**自分が心から信じている正論であること**
- 掛け算の数を増やすほど唯一無二になる

### 市場の構造（調査で判明した事実）
- **この市場は「人名」で検索されている** — JP検索ボリューム上位8件のうち4件が個人名
  （つくし 41,060 / うみぞう 29,993 / えだまめ 29,565 / みずき 28,084）
- 「えだまめ」は**登録1,270人で検索ボリューム29,565**。掛け算が立てば規模と無関係に第一想起が取れる実例
- トレハン部の名前はこのリストに入っていない

### 仮説と現在の推奨
- ユーザーの当初仮説：「**利益商品の情報を教える発信者はクソ**」というポジション
- 検証結果：**空いている**。かつ叩くべき大きな流派（いとう社長「リサーチ不要・利益商品が自宅に届く」10.7万再生）も立っている
- ただし**そのままだと自己否定になる**（トレハン部自身が「今月売れた利益商品TOP10」を定例でやっている）
- → 推奨は否定ではなく「手前」を取る言い換え：**「棚を読む」せどり**
  （商品を探すな、棚を読め。なぜこの棚にこの商品があるのか）
- **未確認**：部長・TOMY・ぬっきーが本当にそう信じているか（たくと氏の成立条件）
