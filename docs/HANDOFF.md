## 4・5の実行結果（2026-09-13）

APIキーを発行してもらって実行した。競合12チャンネル30本、**915スレッド（返信782件込み）**を取得。
うち**681件（40%）が発信者本人の返信**だったので、視聴者の声は1,016件。

結果は `docs/comment-insights.md`。要点は3つ。

1. **「棚を読む」は視聴者の言葉ではない。** 棚・値付け・品出しに触れたコメントは630件中2件。
   ポジショニング案Aをそのままキーワードにはできない
2. **ただし仮説の中身は支持される。** 「どこで仕入れるか」を聞く人は4件。対して
   売れ残り20件・規制/真贋25件・税金23件・数字の検算26件で合計94件。
   視聴者が知りたいのは探し方ではなく**買ったあとどうなるか**
3. → 推奨を「棚を読む」から **「売り切るまで見せる」** に修正した。
   競合30本すべてが仕入れた瞬間（利益◯円）で動画を終えていて、
   その商品が何日後にいくらで売れたかを出している発信者がいない

**母数の注意**：1,016件のうち386件が「せどり名人【FBA納品手順】」1本に集中している。
テーマ集計はこの1本を除いた630件で数えた（除かないと梱包・発送が14.9%まで膨らんで傾向が歪む）。

**再実行するとき**
```bash
export YOUTUBE_API_KEY=...
python3 tools/fetch_comments.py --stage videos
python3 tools/fetch_comments.py --stage comments
python3 tools/analyze_comments.py --dump
```
yt-dlp 版（`--stage scan` → `videos` → `comments`）はAPIキーが無いときの代替。
並列で走らせると bot 判定に当たるので `--delay` は下げない。

4. **ポジショニング仮説の検証** — 「棚読み」仮説の裏付けと**反証の両方**
5. **視聴者の属性と語彙** — 年齢・性別・地域・資金規模・本業、実際に使っている言葉（台本とタイトルの語彙設計用）

## 議論の前提（ここまでの結論）

### 脳内SEOとは
たくと氏（@たくと.YouTube攻略）の概念。「視聴者の頭の中で、あるキーワードの第一想起を取る」ゲーム。
- 競合が入口（再生数）を取っているなら、自分は**出口**（売上）を取る
- **後発が有利**：先発は設計が緩いので弱点を突かれると弱い。大きい流派が立っているからこそ反対意見の流派が成立する
- 成立条件：**自分が心から信じている正論であること**
- 掛け算の数を増やすほど唯一無二になる

### 市場の構造（調査で判明した事実）
- **この市場は「人名」で検索されている** — JP検索ボリューム上位8件のうち4件が個人名
  （つくし 41,060 / うみぞう 29,993 / えだまめ 29,565 / みずき 28,084）
- 「えだまめ」は**登録1,270人で検索ボリューム29,565**。掛け算が立てば規模と無関係に第一想起が取れる実例
- トレハン部の名前はこのリストに入っていない

### 仮説と現在の推奨
- ユーザーの当初仮説：「**利益商品の情報を教える発信者はクソ**」というポジション
- 検証結果：**空いている**。かつ叩くべき大きな流派（いとう社長「リサーチ不要・利益商品が自宅に届く」10.7万再生）も立っている
- ただし**そのままだと自己否定になる**（トレハン部自身が「今月売れた利益商品TOP10」を定例でやっている）
- → 推奨は否定ではなく「手前」を取る言い換え：**「棚を読む」せどり**
  （商品を探すな、棚を読め。なぜこの棚にこの商品があるのか）
- **未確認**：部長・TOMY・ぬっきーが本当にそう信じているか（たくと氏の成立条件）
