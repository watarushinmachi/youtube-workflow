## 4の実行ログ（2026-09-13）

ローカルの yt-dlp なら APIキーなしでコメントまで取れるので、そちらで走らせた。

**できたところ**
- 22チャンネル 3,413本を一覧取得（`data/scan.json`）
- 仕入れ企画のフィルタ（8分以上 × タイトルに仕入れ系の語）で 1,288本に絞り込み
- うち 261本の再生数・コメント数を取得（`data/meta_cache.json`）

**止まったところ**
6並列で再生数を取りにいったところで YouTube 側の bot 判定に当たり、
`Sign in to confirm you're not a bot` が出て以降ぜんぶ失敗するようになった。
IP単位のブロックなので、同じ回線からは時間を置くまで yt-dlp でのアクセスができない。

対策としてスクリプトは直列＋2秒待ち＋連続失敗時のクールダウンに書き換え済み。
ブロックが解ければそのまま再開できる（`meta_cache.json` があるので取得済みの分は再取得しない）。

**261本時点で見えていること**（参考値・確定ではない）
- 再生数の上位はうみぞうの「1日密着」型が独占（688,956回 / 211,265回 / 72,335回 …）
- トレハン部の最上位は「セカスト/オフハウスで簡単に真似できる仕入れ方法」71,821回
- 密着系はコメントも多い（うみぞう 208件）。コメント抽出の母数として密着系が効く

**残っている選択肢**
1. YouTube Data API v3 のキーを発行する（下の手順）。ブロックと無関係に動くので確実
2. yt-dlp のブロックが解けるのを待って直列で再開する（解除時間は不明）

## 5で出すもの（依頼された抽出軸）

ユーザーの指定は「**未充足ニーズ / 物販界隈への不信感 / 結果が出ない理由 / ポジショニング観点 + 幅広く**」。
全スレッドを機械的に分類したうえで、以下を出す。

4. **ポジショニング仮説の検証** — 「棚読み」仮説の裏付けと**反証の両方**
5. **視聴者の属性と語彙** — 年齢・性別・地域・資金規模・本業、実際に使っている言葉（台本とタイトルの語彙設計用）

## 議論の前提（ここまでの結論）

### 脳内SEOとは
たくと氏（@たくと.YouTube攻略）の概念。「視聴者の頭の中で、あるキーワードの第一想起を取る」ゲーム。
- 競合が入口（再生数）を取っているなら、自分は**出口**（売上）を取る
- **後発が有利**：先発は設計が緩いので弱点を突かれると弱い。大きい流派が立っているからこそ反対意見の流派が成立する
- 成立条件：**自分が心から信じている正論であること**
- 掛け算の数を増やすほど唯一無二になる

### 市場の構造（調査で判明した事実）
- **この市場は「人名」で検索されている** — JP検索ボリューム上位8件のうち4件が個人名
  （つくし 41,060 / うみぞう 29,993 / えだまめ 29,565 / みずき 28,084）
- 「えだまめ」は**登録1,270人で検索ボリューム29,565**。掛け算が立てば規模と無関係に第一想起が取れる実例
- トレハン部の名前はこのリストに入っていない

### 仮説と現在の推奨
- ユーザーの当初仮説：「**利益商品の情報を教える発信者はクソ**」というポジション
- 検証結果：**空いている**。かつ叩くべき大きな流派（いとう社長「リサーチ不要・利益商品が自宅に届く」10.7万再生）も立っている
- ただし**そのままだと自己否定になる**（トレハン部自身が「今月売れた利益商品TOP10」を定例でやっている）
- → 推奨は否定ではなく「手前」を取る言い換え：**「棚を読む」せどり**
  （商品を探すな、棚を読め。なぜこの棚にこの商品があるのか）
- **未確認**：部長・TOMY・ぬっきーが本当にそう信じているか（たくと氏の成立条件）
